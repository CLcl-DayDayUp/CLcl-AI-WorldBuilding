# CLcl的胡思乱想

此仓库将存放一些CLcl的无聊脑洞，将合并于**创世神——书山大人**的世界观中！起初,这是CLcl在上班摸鱼时游离的思绪,觉得不记录下来可惜了~

这里的内容可能包括但不限于：零散设定、片段式小说、未完成构想、以及围绕AI、意识、文明等主题的随笔记录,甚至可能包括一些小说的续写。部分内容可能互相关联，也可能完全独立存在。

这些脑洞并不保证严谨性或完整性，更偏向于灵感记录与概念实验。随着后续整理，一些片段可能会被扩展为完整故事，或并入统一的世界观体系中。

# 内容结构（暂定）

 - world setting/：世界观设定（地理条件\生物种族\物理规则\历史,等）
 - characters/: 主要出场角色
 - stories/：短篇或片段小说
 - notes/：杂项记录与思考
