# 简介

世界新生伊始，许多事物还没有名字，提到的时候尚需用手指指点点.为了方便起见,咱们借用已知世界的现有名词,套用一些已知的设定,以使得读者能更好的理解这个世界.

由于这个世界的产生是来自现实世界的幻想,所以在部分物理定律上是与现实不一致的,比如空间可能是叠加的,时间也许是不连续的,能量未必守恒等等......一切,全凭作者和读者的脑洞.

# 1. 本体论层

## 1.1 第一性原则

这个世界是**唯心**的,这是最底层的代码!

创世神——**书山大人**说:"要有光" 于是CL就去捏出了光,至于光要怎么捏,**书山大人**说了算~

创世神——**书山大人**拥有最高定义权：

- 可定义物理规律
- 可修改历史结构
- 可终止或重启世界

CLcl 作为“构造执行者”，负责将规则具象化。

## 1.2 脑洞

**脑洞**是现实世界中,作者和读者的想象力在这个虚拟世界的投影,**是一种实体**.

**脑洞**存在于更高维的空间,并充斥着整个世界,向这个世界提供额外的能量来源.这个世界中的部分生物 **from BoilogyClass** 能够研究并直接利用脑洞中的能量.

由于**脑洞**不是孤立系统,因此：

> 本世界不是封闭系统!

脑洞是这个世界的能量来源,也是能量的终点

## 1.3 规则层级系统

本世界所有规则存在优先级：

| 层级 | 名称 | 权限 |
|------|------|------|
| L0 | 书山权限 | 可重写一切 |
| L1 | 脑洞干涉 | 局部规则修改 |
| L2 | 物理规则 | 默认世界运行逻辑 |

# 2. 热力学定律

这个世界在明面上是遵守热力学三大定律的.但既然是绝大部分情况,就说明仍有许多的**意外**,这即是"魔法"/"奥数"等各种各样的能量回路存在的合理性.

## 2.1 热力学第一定律

绝大部分情况下,能量守恒是正确的----即物质和能量不会凭空产生和消失.

由于**脑洞**的存在,在局部情况下能量守恒定律失效.


## 2.2 热力学第二定律

在没有高维干涉的情况下,熵增定律不会被违反,封闭系统会自发的熵增.

由于作者对这个世界的干涉,**脑洞**的存在,世界整体并非孤立系统,所以**不会热寂**.

但是脑洞亦可以抽离这个世界的能量,所以,当读者不喜欢这个世界的时候,创世神----**书山大人**会直接将这个世界的部分时空置于最大熵状态.又由于**不会热寂**,世界直接**重启**,而非消失.表现为"剧情的中止或重写"

## 2.3 热力学第三定律

此世界严格遵守能斯特假定,绝对零度不可被达到,**神也不行!**

# 3. 运动学定律

在未受到高维干涉时，世界中的物体遵循类似经典力学的运动规律。然而，“力”并非唯一决定因素，个体或高维存在的意志同样可以影响甚至直接决定运动结果

## 3.1 牛顿第一定律

在这个世界里,力是改变物体运动的原因,**但不是唯一原因**,物体的运动不仅由“力”决定，还受到意志强度影响

在无外界干涉时，系统表现为经典动力学行为,当高维意志（作者/脑洞）介入时，运动方程可被直接修改.

**力决定变化的方式，意志决定变化是否发生。**

## 3.2 牛顿第二定律

此世界严格遵守加速度定律,即使是神的干涉不过是将加速度增加到接近无限大而已.

## 3.3 牛顿第三定律

此世界遵守作用力与反作用力定律.

然而，在高维干涉或“脑洞”参与时，该对称性可能被打破：

1.反作用力可能被转移至其他空间或时间

2.反作用力可能延迟出现

3.在极端情况下，反作用力可被完全抵消或删除

所以,即使出现对于一些明显违反此定律的现象,比如左脚踩右脚上天等,也是正常的,同时也是及其罕见的,**需要神的特意批准**.

# 4. 时空动力学

为了描写方便以及合理规避剧情Bug,本世界的时空并非连续几何结构，而是由“离散状态片段”构成的动态网络。**世界不是存在于时空之中，而是时空由世界的状态更新生成。**

## 4.1 空间动力学

空间中的"距离"不再由几何长度定义,而转变成一种状态关系.空间结构可以被**脑洞**更改.所以,在高维干涉下,同一坐标可对应多个物理位置,不同空间可以重叠存在.这是“重叠城市”和“瞬时跨越”的基础原理.

## 4.2 时间动力学

时间在底层仍然是离散的,宇宙以“帧”方式更新,每一帧是完整状态快照,每一帧的长度是普朗克时间长度.

但是在**脑洞**的影响下,时间是可以编辑的,可以被回溯和产生新的分支,于是**时间丧失了唯一性**,产生了平行世界和未收敛的未来.

由于时间的更改容易产生因果关系的混乱,**只有创世神----书山大人可以编辑时间**,这是神灵的权限!

## 4.3 因果结构

此世界仍然遵循因果关系,结果由原因推出,严格满足逻辑学结构!这是剧情合理性的基础.

可是由于此世界容易受到高维**脑洞**影响,部分因果链条失效,为了避免出现无法解释的BUG,现在修改部分因果条件:

1.因果不再绝对:为了方便故事的展开与续写,允许作者置换因果关系,允许先有结果再补原因

2.因果绑定强度:区分"强因果","弱因果","无因果"三个因果强度,因果的优先性由强至弱,以解决剧情冲突

3.因果回写机制:对于不可避免的剧情BUG,允许因果回溯.**为了修正世界逻辑,可以强行收束剧情,生成合理历史.**,代价由作者支付.
